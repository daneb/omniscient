# Design — durable-capture

## Approach

Set the busy timeout in `Storage::new` immediately after opening, before the
first statement. Failures append to a log beside the database rather than being
printed, because the hook discards both streams. `doctor` reads that log so the
failure count is reachable without knowing the file exists.
