# Design — hook-portability

## Approach

Invert the guard. Today capture is conditional on the timer having been set, so
a timing failure suppresses the record. Instead mark that a command ran, and
treat the duration as a best effort: if the clock is unavailable, report 0.

zsh loses its `zsh/mathfunc` dependency entirely — `${$(( expr ))%%.*}` truncates
with parameter expansion — and gains an explicit `zmodload zsh/datetime`, which
is idempotent and cheap. There is no pure-zsh sub-second wall clock, so that
module is loaded rather than avoided.

bash drops `date +%s%N` for bash 5's built-in `$EPOCHREALTIME`, falling back to
no timing where that is absent. BSD date has no `%N` and there is no portable
substitute worth a dependency.
