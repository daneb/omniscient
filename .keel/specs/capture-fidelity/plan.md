# Design — capture-fidelity

## Approach

Both hooks stash the command in `preexec` (`$1`) into a shell-local variable and
read it in `precmd`. The seam is the generated string in `src/shell.rs`; nothing
in the Rust capture path changes. Shell-level tests run the real hook under
`zsh -f` with each history option set, because the bug only exists in the
interaction between the hook and those options.
